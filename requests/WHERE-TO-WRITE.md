# Which archive holds which parish

**This was got wrong first time and is worth writing down.** The drafts in this
folder were originally addressed to the **Državni arhiv u Gospiću** on the
assumption that Lika-Senj county means Gospić. It does not.

> *Državni arhiv u Gospiću … djeluje na području Ličko-senjske županije,
> **osim gradova Senja i Novalje**.*

Gospić covers Lika-Senj **except the towns of Senj and Novalja**. And
**Smokvica Krmpotska is not in Lika-Senj at all** — it is in Primorje-Gorski
Kotar, under Novi Vinodolski. So almost everything this archive needs belongs to
**Rijeka**, not Gospić.

| Place | Whose records | Archive |
|---|---|---|
| **Senj** — Papić, Blažević, Vukelić, Kosina, Boras | town of Senj | **Rijeka**, Senj branch |
| **Sv. Jakov Krmpote / Smokvica Krmpotska** — Blažević | Novi Vinodolski, PGŽ | **Rijeka**, Senj branch |
| **Krivi Put** — Prpić | City of Senj | **Rijeka**, Senj branch |
| **Selce, Crikvenica** — Antić-Papa, Jelličić | PGŽ | **Rijeka**, Senj branch |
| **Otočac** — Žubrinić | Lika-Senj, not Senj | **Gospić** |
| **Karlobag** — Pilipić, Uroda, Smojver, Gerkacs | Lika-Senj, not Senj | **Gospić** |

## A caution

These addresses were checked from the archives' own contact pages in **September
2026**. Croatian institutional email has migrated once already — several
directories still list `drzavni-arhiv@ri.t-com.hr` for Rijeka, which the archive's
own page has replaced. **Check the contact page before sending.**
